# Pre-registration: Encoder and HCQ 2×2 ablation on the deployed recipe, no LLM (evening of 2026-10-04, Beijing time)

Two confirmatory claims sharing one batch of runs:
- ablation-nl-enc-hcq-2x2-v1: encoder plus HCQ together, looking at macro MSE;
- ablation-nl-hcq-lowbw-v1: HCQ alone, looking at low-bandwidth MSE.

The criteria of the two claims in registry/preregistrations/prereg_36.md (hereafter the original 2×2) are kept unchanged; only the recipe is replaced by the deployed recipe.

## Recipe (shared by the four cells, i.e. the training recipe of the deployed estimator)

Training reuses the code directory of the no-LLM arm of llm-indispensability-mt-anchor-3seed, with the four files IQL.py, module.py, model.py, dualEncoder.py unchanged bit for bit.
- Fifteen features, capacity anchor: Huber regression of the policy mean on true capacity, weight 1.0, knee 1 Mbit/s.
- Training length and optimization: 50,000 steps, batch 512, three optimizers with learning rate 3e-4.
- IQL parameters: β 3.0, τ 0.7, γ 0.99.
- Training set and replay buffer: the same MRE_4, buffer 3.5M.

The encoder and the reward differ in two places:

| Cell | Encoder | Reward | Seeds |
|---|---|---|---|
| C-B | conference-version StateEncoder: Linear(150,1024), LayerNorm, LeakyReLU, outputting one vector fed directly to the head | λ 0 | 0, 1, 2, 3, 4 |
| C-H | same as above | λ 0.4, error term clipped to 5 | 0, 1, 2 |
| M-B | the deployed four-path multi-scale encoder: two layers of aggregators, readout of the last token | λ 0 | 0, 1, 2 |
| M-H | same as above, i.e. the deployed estimator | λ 0.4, error term clipped to 5 | 0, 1, 2, 3, 4 |

- **Encoder.** The estimator.py of the two conference-encoder cells (C-B, C-H) is generated by scripts/encoder/make_nl2x2_conf_arm_v1.py, changing only the encoder and the readout in bwe_agent, sha256 d58e0cae….
  - The original 2×2's split-and-sum 15-token formulation is not used: with no LLM and reading only the last token, that token contains only the 15th feature, and the comparison would be unfair.
  - Parameter counts: C 683,160, M 926,888, of which 220,500 in M belong to the temporal attention module that does not enter the output.
- **Reward.** λ is given by the command line --reward_lambda, and the same MRE_4 is relabeled by the relabel inside IQL.py: λ 0 leaves only the quality term, λ 0.4 is HCQ.
- **Reused runs.** Seeds 0, 1, 2 of M-H reuse the already-trained NLs0 to NLs2 of llm-indispensability-mt-anchor-3seed, same code directory, same hash, same command line (differing only in the --env name).
- **New runs.** 13 in total: M-H seeds 3, 4, M-B three times, C-H three times, C-B five times.
- **Endpoint only.** Only the 50000-step checkpoint is read.

## Evaluation protocol

- **Evaluation script.** Same as for the reused NLs0 to NLs2: gpu-server-2 /path/to/server/work/llm_value/eval_value_per_file.py, chunk 256, GPU.
- **Validation set.** /path/to/challenge/solution/validation/prepare_scenario, 870 calls in total: high bandwidth 77, low bandwidth 469, the two fluctuation directories merged 324.
- **Per-call MSE.** Per call, nanmean of the stepwise squared error, in squared Mbit/s.
- **Aggregation.** Calls are averaged within a scenario, and macro is the simple average of the three scenarios. Each cell first averages the MSE of its seeds on the same call.

## Claim one: ablation-nl-enc-hcq-2x2-v1 (encoder plus HCQ, macro MSE)

Identical to claim one of the original 2×2:
- **Primary endpoint.** (C-B − M-H) / C-B × 100, each of the two cells using seeds 0 to 4.
- **Interval.** Scenario-stratified paired resampling of calls, 10000 times, seed 20260909, 90% interval.
- **Threshold.** 1.631%.
- **Safety line.** When in any scenario the scenario MSE of M-H is higher than that of C-B, the macro rise caused by the worsening in that scenario is computed as the difference divided by 3, then by the macro value of C-B. More than 1% crosses the safety line.
- **Conclusion.**
  - holds: the lower bound is greater than 0, the point estimate is not below 1.631%, and the safety line is not crossed;
  - direction only: the point estimate is positive, but the holds condition is not met;
  - does not hold: the point estimate is not positive, or the safety line is crossed.
- **Invalidation.** It is invalidated if any of the following occurs: the code hash does not match; any run lacks the 50000-step checkpoint; the evaluation export does not align to 870 calls; the reused NLs0 to NLs2, when re-evaluated, differ from the registered value in macro by more than one part in a thousand.

## Claim two: ablation-nl-hcq-lowbw-v1 (HCQ alone, low-bandwidth MSE)

Identical to claim two of the original 2×2:
- **Primary endpoint.** (base two-cell average − HCQ two-cell average) / base × 100. The base two cells are C-B and M-B; the HCQ two cells are C-H and M-H; each cell uses only seeds 0, 1, 2.
- **Interval.** Paired resampling of the 469 low-bandwidth calls, 10000 iterations, seed 20260909, 90% interval.
- **Threshold and safety line.** Threshold 1.631%; the safety line is judged on macro MSE: it is crossed if the macro rise caused by the worsening of any one scenario exceeds 1%.
- **Three-tier conclusion and invalidation.** Same as claim one.

## Report only

- Encoder main effect: M vs C under the same reward, seeds 0 to 2, point estimates and 90% intervals for macro and low-bandwidth separately.
- Macro reading of the HCQ main effect.
- Interaction term.
- MSE, overestimation rate, and underestimation rate for each scenario in the four cells.

## Predictions unfavorable to us

1. **The encoder main effect may be negative at the macro level.** The conference-version single-vector encoder plus capacity anchor may already be close to the level of supervised regression. In Table I, the macro value of the supervised MLP is 2.345. So claim one may come out only as direction only, or even as does not hold.
2. **The low-bandwidth main effect of HCQ is within plus or minus 2%.** The reason is that capacity anchor already directly regresses capacity.
3. **M-B may not be worse than M-H.**
4. **The macro values of all four cells are between 5.5 and 6.5.**
