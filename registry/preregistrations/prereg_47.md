# Pre-registration: Professional blind labeling of ground truth (2026-10-03)

Blind labeling sheet (not released; generated by scripts/paper/make_gt_blind_sheet_v1.py; candidate fields are the same as those seen by each method, in alphabetical order; links have in-page anchors removed; the sheet contains no ground-truth labels). The answer key (an internal sheet) is not sent to the engineer.

## Comparison criteria (fixed before the labels were collected)

- Primary readout: agreement rate on the 84 cells scored under the current ground truth (36 same quantity, 48 no counterpart). For a same-quantity cell, agreement requires the engineer to select same quantity as well, with the field, the differencing and the coefficient (within 2% relative error) all matching; for a no-counterpart cell, the engineer must also select no counterpart.
- Report only: agreement rate and Cohen kappa on the three-class labels (same quantity, different definition, no counterpart) across 285 cells; the distribution of the engineer's choices on cells where the current ground truth is different definition; and an itemized list of cells where the engineer selected same quantity but the current ground truth does not.
- Disagreement handling: each disagreement is checked against the official original text, and the basis is written down by the LLM and reviewed by the authors. If the engineer is right and the current ground truth is wrong, the ground truth is corrected following the practice of version 3 (the label is changed to the engineer's, or, if disputed, to different definition and excluded from scoring), all methods are rescored against the same new ground truth, and this is registered as a post hoc revision with the original verdict retained. If the current ground truth is correct, it is not changed and the disagreement is reported as is.
- No threshold for holds is set; this is a measure of label quality, not a method claim; any agreement rate is reported as is.
